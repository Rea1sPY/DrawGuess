# حدس نقاشی 🎨 — بازی آنلاین فارسی با کد اتاق

یکی نقاشی می‌کشد، بقیه حدس می‌زنند. بدون ثبت‌نام؛ فقط کد اتاق ۵ رقمی.
روی گوشی و کامپیوتر، داخل مرورگر اجرا می‌شود (نیازی به نصب برنامه نیست).

**ساخته‌شده توسط ReaLsPY · تلگرام: @MateoHastam**

## امکانات
- ۲ تا ۱۲ بازیکن، ساخت اتاق و ورود با کد یا لینک دعوت
- بوم نقاشی همزمان (لمسی و ماوس)، ۱۲ رنگ، ۴ اندازه قلم، پاک‌کن، برگردان، پاک کردن همه
- انتخاب ۱ از ۳ کلمه، راهنمای حروف که رفته‌رفته باز می‌شود، امتیاز بر اساس سرعت حدس
- گفتگو، «نزدیک شدی!»، سکوی برندگان، بازی دوباره، اتصال مجدد بعد از رفرش
- ۱۵۲۱ کلمه فارسی در ۴۹ دسته (بانک کلمات فقط روی سرور است و به مرورگر فرستاده نمی‌شود؛ تقلب ممکن نیست)
- بدون هیچ وابستگی: `npm install` لازم نیست (فقط Node.js)

## راه ۱: اجرای آنلاین روی Render (رایگان)
۱. در github.com یک مخزن جدید بسازید، مثلاً `draw-guess`.
۲. این فایل‌ها را در **ریشه** مخزن آپلود کنید: `server.js`، `core.js`، `words.js`، `package.json`، `render.yaml`، `README.md` و پوشه `public` (شامل `index.html`، `style.css`، `app.js`). پوشه `tests` اختیاری است.
۳. به render.com بروید و با حساب GitHub وارد شوید.
۴. **New +** ▸ **Web Service** ▸ مخزن `draw-guess` را انتخاب کنید.
۵. تنظیمات: Runtime = **Node** · Build Command = `npm install` · Start Command = `npm start` · Instance Type = **Free**. سپس **Create Web Service**.
۶. چند دقیقه صبر کنید تا وضعیت **Live** شود. آدرس بالای صفحه (مثل `https://draw-guess-xxxx.onrender.com`) لینک بازی شماست.
۷. لینک را باز کنید ▸ «ساخت اتاق جدید» ▸ دکمه «دعوت» را بزنید و برای دوستانتان بفرستید.

نکته‌ها:
- سرویس رایگان Render بعد از حدود ۱۵ دقیقه بی‌استفاده بودن می‌خوابد؛ اولین باز کردن ممکن است ۳۰ تا ۶۰ ثانیه طول بکشد.
- اتاق‌ها در حافظه سرور هستند. اگر سرور دوباره راه بیفتد، اتاق‌های فعال از بین می‌روند.
- نام دکمه‌ها در Render ممکن است کمی فرق کرده باشد؛ مسیر کلی همین است.
- اگر Render یا GitHub بدون VPN برای شما یا دوستانتان باز نمی‌شود، از «راه ۲» استفاده کنید یا به من بگویید تا سرویس دیگری را بررسی کنیم.

## راه ۲: اجرا روی لپ‌تاپ خودتان (همان وای‌فای، بدون اینترنت)
۱. از nodejs.org نسخه **LTS** را نصب کنید.
۲. پوشه پروژه را باز کنید، روی نوار آدرس File Explorer بزنید، `cmd` بنویسید و Enter بزنید.
۳. بنویسید: `node server.js` ← پیام «حدس نقاشی روی پورت ۳۰۰۰ اجرا شد» می‌آید.
۴. در همان cmd بنویسید `ipconfig` و عدد **IPv4 Address** را پیدا کنید (مثلاً `192.168.1.20`).
۵. روی لپ‌تاپ `http://localhost:3000` را باز کنید و بقیه با گوشی روی **همان وای‌فای** `http://192.168.1.20:3000` را باز کنند.
۶. اگر ویندوز درباره Firewall پرسید، **Allow access** را برای شبکه خصوصی بزنید.

## فونت
بازی از فونت **وزیرمتن** استفاده می‌کند و آن را از اینترنت (Google Fonts / jsDelivr) می‌گیرد؛ اگر در دسترس نبود، از فونت فارسی خود دستگاه استفاده می‌کند.
برای فونت ثابت و بدون اینترنت: فایل `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را در `public/fonts` بگذارید و در `public/style.css` بالای فایل این را اضافه کنید:
```css
@font-face { font-family: 'Vazirmatn'; src: url('fonts/Vazirmatn-Regular.woff2') format('woff2'); font-weight: 400; }
@font-face { font-family: 'Vazirmatn'; src: url('fonts/Vazirmatn-Bold.woff2') format('woff2'); font-weight: 700 900; }
```

## ساختار
```
server.js    سرور HTTP + SSE (بدون وابستگی)
core.js      قوانین بازی: اتاق، نوبت، امتیاز، نقاشی، حدس
words.js     بانک کلمات (فقط سمت سرور)
public/      index.html · style.css · app.js  (ظاهر بازی)
tests/       تست‌ها
```
- ارسال از سرور به بازیکن‌ها با SSE و از بازیکن به سرور با POST انجام می‌شود (بدون WebSocket؛ روی هاست‌های رایگان هم کار می‌کند).
- تنظیمات زمان و مهلت‌ها در بالای `core.js` (`DEFAULT_CFG`) و امتیازها در تابع `guess` است.

node tests/run-tests.js        # منطق بازی + سرور واقعی (۳۶ تست)
python3 tests/ui-test.py       # دو مرورگر واقعی (نقاش و حدس‌زننده) — نیاز به playwright
